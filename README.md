# Marah Content Studio — مرح

أساس التوثيق لمشروع «مرح»: محتوى تعليمي باللهجة المصرية للأطفال من عمر سنتين إلى ٦ سنوات، بشخصيات ثابتة وتحريك فعلي ومراجعة بشرية قبل النشر.

المستودع في مرحلة التأسيس. توجد أداة مزامنة Notion مُعدة واختبارات محلية، لكن لا توجد خدمات إنتاج أو مفاتيح API مهيأة، ولا مزامنة نشطة بين Notion وGit. الأدوات المذكورة أدناه مقترحات للتقييم والتنفيذ التدريجي.

## القرارات المعتمدة

- Notion هو المصدر التحريري الأساسي للأفكار والنصوص وحالات المحتوى: ١٠٠ فكرة، منها ٤٠ فيديو طويلًا و٦٠ قصيرًا. التصدير المنقول يتضمن ١٠٠ بطاقة بهذه القسمة؛ النقل الحالي لقطة من المصدر، وليس مزامنة مستمرة.
- كل حلقة لها هدف تعليمي واحد: تقديم نموذج، ثم ممارسة، ثم سؤال مع انتظار ٢–٣ ثوانٍ، ثم إجابة، ونشاط بسيط مع ولي الأمر.
- الصوت باللهجة المصرية يُراجع ويُعتمد منفصلًا قبل توقيت التحريك.
- الشخصيات تتحرك فعلًا؛ تحريك الكاميرا فوق صور ثابتة وحده لا يحقق المطلوب.
- تُراجع النسخة النهائية، ثم يوافق المستخدم صراحة قبل أي نشر عام على YouTube أو Facebook أو Instagram أو TikTok.

## تنظيم المستودع

| المسار | الحالة والمحتوى |
| --- | --- |
| `docs/` | موجود: توثيق البنية والإنتاج والتكاملات والمزامنة |
| `content/notion/README.md` | موجود: فهرس ١٠٠ بطاقة، ٤٠ طويلًا و٦٠ قصيرًا |
| `content/notion/pages/<NotionID>.md` | موجود: ١٠٤ صفحات Markdown بروابط محلية أعيد توجيهها |
| `content/notion/assets/*.png` | موجود: ٤ صور من التصدير |
| `content/notion/data/*.csv` | موجود: ملفا CSV من التصدير |
| `content/notion/manifest.json` و`pipeline.json` | موجود: بيان النقل وبيانات البطاقات المنظمة |
| `automation/scripts/sync_notion.py` | موجود: أداة مرآة API محددة النطاق، غير مشغلة فعليًا |
| `automation/notion-sync.config.json` | موجود: نطاق القراءة ومسار الإخراج |
| `.github/workflows/notion-sync.yml` | موجود: تشغيل يدوي وكل ساعة؛ متوقف حتى إعداد السر والمتغير |
| `automation/workflows/notion-sync.yml.template` | موجود: قالب مرجعي |
| `tests/test_sync_notion.py` | موجود: ٧ اختبارات محلية للمزامنة |
| `content/notion/api-current/` | مستقبلي: مخرجات JSON وأصول API عند أول تشغيل ناجح |
| أتمتة الإنتاج وتخزين مخرجاته | مستقبلي: يُضافان عند التنفيذ، دون إنشاء مجلدات أو تطبيقات شكلية |

التصدير الحالي محفوظ في هذه المسارات مباشرة، دون مجلد `rawexport/`. لا تُحرر صفحات المصدر أو أصوله أو بياناته يدويًا. مرآة API المستقبلية منفصلة ومحدودة بما تسمح الواجهة بقراءته، وليست بديلًا كاملًا لتصدير Notion.

من جذر المستودع، شغّل الفحوص المحلية:

```sh
python -m unittest discover -s tests -p 'test_sync_notion.py'
```

بعد توفير `NOTION_TOKEN` في البيئة ومنح التكامل صلاحيات القراءة المحددة فقط، يمكن تشغيل المزامنة يدويًا:

```sh
python automation/scripts/sync_notion.py --config automation/notion-sync.config.json
```

لا يحتاج الاختبار إلى السر؛ يحتاج التشغيل الفعلي إليه. راجع [دليل المزامنة](docs/notion-sync.md) قبل التفعيل.

النقطة التالية هي مراجعة مخطط البيانات وطريقة مزامنة Notion، ثم إنتاج حلقة تجريبية واحدة ضمن ميزانية محددة. راجع [خريطة التنفيذ](docs/roadmap.md) لمعايير الانتقال بين المراحل.

هذا المستودع لا يمنح ترخيصًا لحقوق المستخدم أو الشخصيات أو مواد المحتوى. لا تضف ترخيصًا عامًا دون موافقة صاحب الحقوق.
