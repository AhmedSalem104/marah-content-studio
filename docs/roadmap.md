# خريطة التنفيذ

> الوضع الحالي: إنتاج مانوال للشهر الأول. راجع [دليل التشغيل](manual-production.md) و[جدول الشهر الأول](month-01-calendar.md). أي مراحل API أو سيرفر أو أتمتة أدناه مرجع للتوسع وليست شرط بدء.

المراحل أدناه مقترحة للتنفيذ المتدرج. التوثيق والتصدير المنقول وأداة المزامنة واختباراتها موجودة؛ التكاملات الخارجية ومزامنة API لم تُشغّل.

| المرحلة | العمل | شرط الانتقال |
| --- | --- | --- |
| ٠ — الأساس | تثبيت الهوية التعليمية والشخصيات وقواعد الصوت والتحريك والموافقة | مراجعة هذه الوثائق والتأكد من توافقها مع هدف «مرح» |
| ١ — بيانات Notion | التصدير الخام الحالي منقول؛ راجع اكتماله وحدد مخطط المصدر والمعرّفات والعلاقات والمرفقات للمزامنة اللاحقة | مراجعة التصدير: ١٠٤ صفحات و٤ صور وملفا CSV و١٠٠ بطاقة، دون تعديل تحريري للمصدر |
| ٢ — المزامنة | الأداة والإعداد وسير العمل المحجوب موجودة، واجتازت ٧ اختبارات محلية؛ يلزم سر `NOTION_TOKEN` للقراءة فقط ومتغير `NOTION_SYNC_ENABLED=true` ثم تشغيل ناجح | تشغيل موثق يثبت الثبات والتكرار الآمن؛ حتى ذلك الحين المزامنة غير نشطة |
| ٣ — تجربة واحدة | اختيار فكرة واحدة، مراجعة النص، إنتاج الصوت واعتماده ثم تحريك وتجميع فعلي | حلقة كاملة تحقق الهدف وثبات الشخصيات والتوقيت ضمن الميزانية |
| ٤ — أتمتة محدودة | تهيئة التكاملات وسجل الوظائف وسقوف التكلفة والاستكمال وإعادة المحاولة | إثبات عدم تكرار وظيفة مدفوعة واختبار انقطاع ثم استكمال دون إعادة مراحل سليمة |
| ٥ — النشر | تهيئة حسابات المنصات، نسخ الإخراج، وربط الموافقة بالإصدار والبصمة | موافقة المستخدم على نسخة نهائية ثم نشر موثق يمنع التكرار لكل منصة |
| ٦ — التوسع | جدولة تدريجية لخطة ٤٠ طويلًا و٦٠ قصيرًا | قياس جودة وتكلفة ووقت إنتاج مقبول قبل زيادة الحجم |

## الخطوة العملية التالية

إنتاج M01-01 «دودو يستأذن» قصة كاملة وفق جدول الشهر، ثم الريلز M01-02. تجهيز الصوت والمراجع والتحريك والتجميع مانوال، ومراجعة النسخة كاملة قبل نشرها عبر Buffer. لا تؤخر بداية الإنتاج لشراء APIs أو تشغيل سيرفر؛ تقاس تكلفة الشهر قبل الانتقال للأتمتة.

## ما ينتظر الإعداد

مفاتيح API، حسابات النشر وصلاحياتها، تخزين مخرجات الإنتاج وسجل وظائفه وأتمتة الإنتاج غير مهيأة حاليًا. أداة مزامنة Notion مُعدة لكنها غير نشطة؛ تفاصيل التشغيل في [دليل المزامنة](notion-sync.md). قائمة الخيارات والمتطلبات في [التكاملات](integrations.md). قواعد القبول في [مسار الإنتاج](production-flow.md).
