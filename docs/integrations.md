# التكاملات المقترحة

> الوضع الحالي: إنتاج مانوال للشهر الأول. راجع [دليل التشغيل](manual-production.md) و[جدول الشهر الأول](month-01-calendar.md). أي مراحل API أو سيرفر أو أتمتة أدناه مرجع للتوسع وليست شرط بدء.

لا توجد مفاتيح API مهيأة أو تكاملات تشغيلية مؤكدة. أداة Notion وإعدادها وسير العمل `.github/workflows/notion-sync.yml` موجودة مع ٧ اختبارات محلية، لكنها غير نشطة. التشغيل يدوي وكل ساعة وحده الزمني ٣٠ دقيقة، ومحجوب بشرط `vars.NOTION_SYNC_ENABLED == 'true'`. يلزم سر `NOTION_TOKEN` بصلاحيات قراءة فقط والمتغير `NOTION_SYNC_ENABLED=true` قبل تشغيل فعلي. يبقى قالب `automation/workflows/notion-sync.yml.template` مرجعًا غير تنفيذي. هذا جدول خيارات للتقييم، وليس قائمة خدمات معتمدة أو وعودًا بقدرات مزود. راجع وثائق المزود الرسمية عند التنفيذ لأن الحدود والأسعار والصلاحيات تتغير.

## متطلبات مشتركة

تُحفظ الأسرار خارج المستودع. تُوثق أسماء المتغيرات المطلوبة عند اختيار المزود دون قيم فعلية. تُضبط ميزانية إجمالية وحدود لكل مرحلة قبل أي طلب مدفوع، ويُسجل الإنفاق ومعرّف وظيفة المزود. لا تعتمد على إعادة إرسال عمياء عند انتهاء مهلة الطلب؛ افحص حالة الوظيفة القائمة أولًا.

استخدم مفاتيح منع تكرار وسجلًا دائمًا ومحدودية واضحة للمحاولات. يمكن استكمال المراحل الناجحة دون إعادة دفع تكلفتها إذا لم تتغير مدخلاتها. الموافقة مرتبطة بإصدار الأصل وبصمته، وحالة النشر مستقلة لكل منصة. الأخطاء غير المحسومة تتوقف للمطابقة أو التدخل بدل إنشاء وظائف أو منشورات مكررة.

## مزامنة Notion → Git

التصدير الخام الحالي لقطة من Notion، وليس مزامنة عبر API. المزامنة المستمرة معلقة حتى إعدادها والتحقق منها. التصدير الحالي موزع بين `pages/` و`assets/` و`data/` مع الفهرس وبيان النقل و`pipeline.json`، دون مجلد `rawexport/`. الأداة المُعدة تحفظ استجابات API وأصوله في `content/notion/api-current/` منفصلة عن التصدير. تحفظ البيانات المقروءة دون اختصار تحريري، مع استبدال روابط الملفات المستضافة بمسارات محلية. النطاق يستثني التعليقات وسجل الإصدارات والمحتوى غير المتاح والصفحات المرتبطة التي لا تُتبع؛ يعلن البيان أن المرآة جزئية. راجع [دليل المزامنة](notion-sync.md) لحدود الملفات والصلاحيات والتشغيل.

بعد تنفيذ المزامنة، وثق حدود الوصول أو التصدير الفعلية وطريقة معالجة حذف السجلات وتحديثها والتحقق من اكتمالها. لا تصفها بأنها نشطة إلا بعد تشغيل ناجح موثق.

## تحديث الاختيارات — 15 أكتوبر 2026

الجدول أعلاه يصف مرحلة التقييم السابقة. المرجع الأحدث هو [خطة الأتمتة مع Buffer](automation-plan.md): OpenAI API للنص، Nano Banana Pro عبر Gemini API للصور، ElevenLabs API للصوت، Kling 3.0 عبر API للتحريك، وBuffer API للنشر. المنصات المستهدفة حاليًا TikTok وYouTube Shorts وFacebook Page فقط. الربط المباشر بواجهات الشبكات ليس المسار الأساسي؛ لا يُضاف كحل بديل دون قرار موثق. مزامنة الفم لم تُحسم تقنيًا، وتُتحقق قدرات كل قناة وحقول الأطفال قبل تفعيلها. لا مفاتيح أو اتصالات تشغيلية جديدة مؤكدة.
