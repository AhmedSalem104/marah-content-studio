# لوما

- صوت طفولي أنثوي دافئ وواضح.
- سرعة متوسطة، فضول وابتسامة مسموعة.
- تسأل أولًا ثم تساعد على اكتشاف الإجابة.
- لا تستخدم جملًا طويلة.

# دودو

- صوت طفولي ذكوري حيوي.
- أسرع قليلًا من لوما مع حماس واضح.
- أسئلته تلقائية وردود فعله صادقة.
- لا يتحول لصراخ مستمر.

# بوبو

- أصوات كلب مصممة تعبيريًا: فضول، فرح، ارتباك، اكتشاف، خوف خفيف.
- لا جمل بشرية في الوضع الأساسي.
- Motif صوتي قصير يمكن ربطه بدخوله أو اكتشافاته.

# قواعد الأداء

- لهجة القاهرة المصرية البسيطة: إيه، فين، بص، يلا، مع بعض. تُكتب الأسماء لُوما، دُودُو، بُوبُو مع مراجعة النطق الحقيقي؛ لا حركات إعراب أو تحويل الجمل للفصحى.
- تشكيل صوتي للكلمات المحتملة للالتباس دون إفساد المصرية: أَحْمَر، أَزْرَق، أَصْفَر، شُكْرًا، بْرافو. لا نسخ صوت شخص حقيقي أو تقليد طفل معروف.
- تسجيل سطر مستقل لكل شخصية، سرعة مريحة وفواصل طبيعية؛ لا ضغط الكلام لملاحقة مدة الصورة، بل تُضبط مدة المشهد حسب التسجيل.
- سؤال واحد كل مرة ووقفة 2–3 ثوانٍ للإجابة؛ الموسيقى تحت الحوار، لا تغطي كلمات التعليم؛ بوبو نباح وتنفس ومؤثرات فقط.
- ثبات مزود الصوت وvoice ID والإعدادات لكل شخصية؛ الأصوات العامة المصرية تصلح لنسخة أولية، ولا تُعتمد كأصوات أطفال نهائية دون مراجعة مناسبة الأداء.
- مراجعة كل سطر: وضوح الكلمة، اللهجة المصرية، عدم تبديل اسم الشخصية، عدم حذف أو تكرار، وعدم clipping. ثم مراجعة الحوار متصلًا داخل الفيديو. لا تسمى النسخة نهائية إن لم تُسمع وتُعتمد.

# تسمية ملفات الصوت

# Gate

بوابة الاكتمال: ملفات حوار منفصلة محفوظة + مونتاج صوت شامل + تزامن سمعي بصري + استماع كامل. فيديو الصور قد يستخدم تحريك كاميرا دون lip-sync؛ يجب التصريح بذلك. يمنع تسليم فيديو بلا كلام باعتباره حلقة مكتملة. التسجيل المفضل WAV 48kHz، ثم AAC للتسليم؛ تطبيع تقريبي للحوار -16 LUFS وذروة لا تتجاوز -1 dBTP.
