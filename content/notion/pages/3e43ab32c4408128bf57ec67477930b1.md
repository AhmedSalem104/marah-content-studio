# Production System — من الفكرة إلى فيديو جاهز للنشر

<aside>
🎯

**الهدف:** هذا هو الـMaster Production Flow الرسمي للقناة. كل حلقة تمر بنفس البوابات حتى نضمن Premium Kids Animation ثابتة وقابلة للتوسع.

</aside>

# 0 — قواعد المشروع

- **الجودة المستهدفة:** Premium 3D Kids Animation بجودة سينمائية، وليس 3D بسيط أو فيديو AI عشوائي.
- **الأبطال الثابتون:** لوما، دودو، بوبو.
- **الجمهور الأساسي:** 2–6 سنوات.
- قاعدة التعليم V2: هدف تعلم واحد يقود القصة. كل موقف يُظهر نموذجًا عمليًا ومحاولة وتحققًا وتطبيقًا منزليًا؛ الترفيه والمغامرة يخدمان المهارة.
- لا تدخل الحلقة Production قبل اعتماد Script + Character/World references + Storyboard.
- Notion هو **Single Source of Truth** للقرارات والنسخ المعتمدة.

# 1 — Idea & Content Brief

المخرجات المطلوبة: معرف EP/SH، العنوان، الهدف الرئيسي، نتيجة تعلم قابلة للملاحظة، تدرج 2–3 و4–6، موقف مصري، نموذج عملي، سؤال ووقفة، نهاية توضح المهارة، نشاط ولي الأمر، احتياجات الصورة والصوت. جميع بطاقات Content Pipeline المائة محدثة بهذا القالب.

**أنا أتولى:** توليد الأفكار، تقييم التكرار، صياغة الـBrief، واقتراح Hook مناسب.

**Gate:** فكرة واحدة واضحة + هدف تعليمي واحد رئيسي.

# 2 — Story Development

**المخرجات:** Beginning → Conflict → Discovery → Participation → Resolution → Reward.

- تحديد دور لوما ودودو وبوبو في الحدث.
- تحديد لحظات مشاركة الطفل.
- تحديد اللحظة الكوميدية واللحظة العاطفية.

**أنا أتولى:** بناء القصة والإيقاع ومراجعة ملاءمتها للعمر.

# 3 — Script & Dialogue

المخرجات: مشاهد واضحة وحوار مصري مشكول نطقيًا لكل شخصية، وقفات الطفل 2–3 ثوانٍ، توقيت لكل سطر، مؤثرات بوبو، وموسيقى لا تغطي الكلمات. لا راوي افتراضيًا، ولا إعراب فصيح يفسد اللهجة.

**قاعدة الحوار:** جمل قصيرة، واضحة، قابلة للأداء، ولكل شخصية صوت وطريقة كلام ثابتة.

**أنا أتولى:** كتابة ومراجعة جميع النسخ حتى Final Script.

**Gate:** لا Storyboard قبل Final Script.

# 4 — Character Bible & World Bible

## Character Bible

لكل شخصية: الشكل، النسب، الملابس، Palette، تعبيرات الوجه، Personality، طريقة الكلام، الحركة، الممنوعات، Character Turnaround، Character Plates.

## World Bible

المواقع المتكررة، Architecture، props، الإضاءة، palettes، الوقت/الطقس، قواعد العالم.

**الأدوات:** ChatGPT/Image Generation للتطوير البصري والمراجع؛ Blender عند الحاجة إلى أصول 3D حقيقية قابلة لإعادة الاستخدام؛ Runway References كخيار إنتاجي للحفاظ على اتساق الشخصيات والمواقع في المسار التوليدي.

**Gate:** لا توليد Shots نهائية قبل قفل الـReference Pack.

# 5 — Visual Development

لكل حلقة: Moodboard → Color Script → Keyframes → Environment References → Props → Lighting references.

**أنا أتولى:** Art Direction، prompts، مراجعة الاتساق، وإنشاء الصور المرجعية التي أستطيع إنتاجها هنا.

**المخرجات:** Approved Visual Pack.

# 6 — Storyboard

كل مشهد يتحول إلى لوحات تحدد: Composition، مكان الشخصيات، Action، Camera، Dialogue، Transition.

**أنا أتولى:** Shot planning ووصف/إنشاء الـStoryboard references.

**Gate:** القصة مفهومة بصريًا حتى بدون الصوت.

# 7 — Animatic & Timing

ترتيب الـStoryboard على Timeline مؤقت مع الحوار والموسيقى المؤقتة.

**نراجع:** طول الحلقة، سرعة القطع، pauses الخاصة بتفاعل الطفل، اللحظات البطيئة، وضوح القصة.

**Gate:** Picture timing approved قبل صرف وقت/تكلفة على الرندر النهائي.

# 8 — Shot List

لكل Shot نسجل:

- Shot ID مثل SC01-SH010.
- Duration.
- Characters.
- Location.
- Camera size/movement.
- Action & expression.
- Dialogue/SFX/Music.
- Reference image.
- Generation/animation prompt.
- Status + QA notes.

**أنا أتولى:** إنشاء الـShot List والـprompts shot-by-shot.

# 9 — Voice Production

المسار الصوتي المعتمد: نص مشكول → اختيار صوت مصري منفصل لكل شخصية → توليد/تسجيل الأسطر → مراجعة سمعية → تنظيف وتطبيع → ضبط مدة الصورة حسب الكلام → تركيب الحوار ثم المؤثرات والموسيقى. التشكيل لا يضمن انعدام أخطاء النطق.

يجب الاحتفاظ بصوت ثابت لكل شخصية وعدم تغييره بين الحلقات.

**الأداة المقترحة:** ElevenLabs أو تسجيل بشري احترافي؛ القرار النهائي بعد اختبار أصوات الشخصيات.

**تنظيم الملفات:** Character_Episode_Scene_Take.

# 10 — Music & Sound

- Theme/sonic identity ثابتة للقناة.
- Original episode song عند الحاجة.
- Background score يخدم المشهد ولا يغطي الحوار.
- SFX للحركة، البيئة، الكوميديا والانتقالات.

**أنا أتولى:** lyrics، music brief، cue sheet، وتوقيت المؤثرات.

**Gate:** حقوق الاستخدام واضحة قبل النشر.

# 11 — Animation / Video Generation

## المسار A — Hybrid AI Production

المسار الحالي: مرجع ثابت للشخصيات → صورة مستقلة لكل مشهد → تحريك الصورة في منصة الفيديو أو مونتاج صور بحركة كاميرا لطيفة → تركيب صوت مصري منفصل. يوسم مونتاج الصور بوضوح؛ تحريك الكاميرا لا يُعد تحريك أجسام أو lip-sync.

**Runway:** مناسب كأحد أدوات الـAI Video؛ References تدعم اتساق الشخصيات والمواقع، ويمكن استخدام أدوات الحركة/الأداء حسب نوع اللقطة.

## المسار B — Full/Hybrid 3D

Modeling → Texturing → Rigging → Layout → Animation → Lighting → Render → Compositing.

**Blender:** خيار أساسي عندما نحتاج أقصى ثبات وإعادة استخدام للشخصيات والبيئات.

## قاعدة الاختيار

لا نفرض أداة واحدة على كل Shot. اللقطة الحوارية، الحركة المعقدة، establishing shot، أو الأغنية قد تستخدم مسارًا مختلفًا مع الحفاظ على نفس الـArt Direction.

# 12 — Shot QA

كل Shot يفشل إذا ظهر:

- تغير وجه/ملابس/ألوان الشخصية.
- تشوه اليد/الجسم أو props.
- حركة غير طبيعية أو lip sync سيئ.
- Camera motion غير مقصود.
- Background inconsistency.
- خطأ تعليمي أو شيء غير مناسب للعمر.

**النتيجة:** Approve / Revise / Regenerate.

# 13 — Editing

Assembly → Fine Cut → Dialogue → Music → SFX → Transitions → Color → Titles.

**الأداة المقترحة:** Adobe Premiere Pro كخيار مونتاج رئيسي، مع إمكانية استخدام Blender/أدوات compositing حسب اللقطة.

**أنا أتولى:** Edit plan، timestamps، مراجعة النسخة، واقتراح التعديلات.

# 14 — Master QA

- Story continuity.
- Character consistency.
- Audio QA: وجود حوار مسموع كامل؛ استماع فعلي للنطق المصري والأسماء والألوان؛ لا clipping؛ موسيقى أخفض من الكلام. وجود audio stream وحده ليس دليل صحة أو اكتمال.
- Lip sync.
- Music/SFX balance.
- No visual artifacts.
- No accidental text/logos.
- Educational accuracy.
- Age appropriateness.
- Safe-area/cropping.
- مشاهدة كاملة من البداية للنهاية قبل الاعتماد.

# 15 — Packaging

**YouTube Long:** Final master + Title + Description + Thumbnail + metadata + captions/subtitles.

**Shorts:** استخراج لحظات مستقلة من الحلقة وإعادة framing إلى 9:16 عند الحاجة.

**أنا أتولى:** العنوان، الوصف، أفكار Thumbnail، النصوص، Shorts cuts والـmetadata drafts.

# 16 — Publish Ready Gate

لا تتحول الحالة إلى **Ready** إلا عند وجود:

- Final approved video.
- Final audio.
- Thumbnail.
- Title + Description.
- Captions/Subtitles عند الحاجة.
- حقوق الأصول/الموسيقى واضحة.
- QA = PASS.

# 17 — بعد النشر

نسجل تاريخ النشر والرابط والنسخة المستخدمة، ثم نراجع الأداء لاستخراج دروس للحلقات القادمة بدون كسر هوية الشخصيات.

# Operating Plan v1 — الخطة المقترحة للإطلاق والنشر

<aside>
🚀

**الهدف:** إطلاق القناة بجودة عالية وبمخزون جاهز، ثم الحفاظ على إيقاع نشر ثابت يمكن الاستمرار عليه بدون التضحية بالجودة.

</aside>

## 1 — Content Strategy

**مرحلة الإطلاق: أول 12 أسبوعًا**

- Long-form: حلقة رئيسية واحدة أسبوعيًا.
- Shorts: عدد 2 أسبوعيًا مشتقان من عالم الحلقة أو منها، لكن كل Short يجب أن يقدم لحظة مفهومة بذاتها.
- الهدف التشغيلي الشهري: 4 حلقات رئيسية + 8 Shorts.
- لا نطلق القناة بحلقة وحيدة؛ **Launch Buffer = 4 حلقات Long مكتملة + 8 Shorts جاهزة** قبل أول نشر.
- نحافظ دائمًا بعد الإطلاق على Buffer لا يقل عن حلقتين Long جاهزتين.

### توزيع المحتوى لأول 12 Long Videos

- Learning/Adventure: 5.
- Daily Life & Healthy Habits: 3.
- Music-led / Song episode: 2.
- Egyptian culture/world discovery: 2.

التوزيع ليس قيدًا دائمًا؛ نراجعه بعد أول 8–12 حلقة حسب الأداء.

## 2 — Episode Standard

**Long:** 3:30–5:00 دقائق كهدف افتراضي.

- 0:00–0:08 Hook.
- 0:08–0:40 اكتشاف المشكلة/المهمة.
- 0:40–3:20 مغامرة + محاولات + تعليم + كوميديا.
- 2–3 لحظات مشاركة للطفل، مع Pause طبيعية.
- 3:20–4:30 حل + Payoff + تثبيت الفكرة.
- Outro قصير جدًا 3–7 ثوانٍ.
- هدف تعليمي رئيسي واحد فقط.

**Short:** 20–35 ثانية كهدف افتراضي.

- Hook خلال أول 1–2 ثانية.
- فكرة/لعبة/سؤال واحد.
- Payoff سريع.
- لا قص عشوائي من Long؛ يجب أن يعمل الـShort وحده.

## 3 — موعد النشر المقترح

**Timezone:** Africa/Cairo.

- **الحلقة الرئيسية:** الجمعة الساعة **10:00 صباحًا بتوقيت القاهرة**.
- **Short #1:** الثلاثاء الساعة **5:00 مساءً**.
- **Short #2:** الأحد الساعة **5:00 مساءً**.

**سبب الاختيار:** هذه نقطة بداية تشغيلية مناسبة لروتين الأسرة/الأطفال، وليست ادعاءً بأنها أفضل ساعة خوارزميًا. بعد 6–8 أسابيع نراجع بيانات الجمهور ونعدل الساعة إذا ظهر نمط أوضح.

- نستخدم Scheduled Publishing في YouTube Studio لضمان الثبات.

## 4 — Launch Plan

**T-4 إلى T-1 أسابيع:** إنتاج المخزون بدون نشر.

**Launch Week:**

- الثلاثاء: Channel Trailer/Short تعريفي قصير.
- الجمعة 10:00: Episode 01.
- الأحد 17:00: Short مرتبط بـEP01.

**من الأسبوع الثاني:** الأحد Short → الثلاثاء Short → الجمعة Long.

- لا ننشر عدة حلقات Long في أول يوم؛ نعطي كل حلقة مساحة ونحافظ على جدول يمكن استمراره.

## 5 — Content Quality Rules

- كل حلقة: مفيدة، مناسبة للعمر، ممتعة وملهمة.
- نركز على الفضول، الإبداع، اللعب، السلوك الإيجابي والتعلم داخل القصة.
- ممنوع Keyword stuffing، المحتوى المكرر/المضلل، الإنتاج الآلي منخفض القيمة أو الفيديوهات المبنية فقط على تكرار النمط.
- الشخصيات الأصلية لا توضع في مواقف صادمة/غريبة لجذب النقرات.
- Thumbnail جذاب وصادق مع محتوى الحلقة.

## 6 — YouTube Audience & Kids Compliance

- القناة موجهة أساسًا للأطفال 2–6؛ إعداد الجمهور في YouTube يجب أن يعكس ذلك بدقة.
- قبل الإطلاق نراجع إعداد **Made for Kids** على مستوى القناة والفيديوهات.
- تصنيف Made for Kids لا يعني تلقائيًا دخول YouTube Kids؛ الأهلية تعتمد أيضًا على سياسات YouTube Kids ومبادئ الجودة.
- قبل كل Publish نراجع أحدث سياسات YouTube/YouTube Kids الرسمية لأن السياسات قد تتغير.

## 7 — Packaging Standard

لكل Long قبل Ready:

- 3 Title options ثم اختيار نسخة نهائية.
- Thumbnail نهائي 16:9.
- وصف عربي مختصر وواضح.
- Episode number داخليًا؛ لا يلزم وضعه في العنوان العام.
- Captions عربية عند الإمكان.
- Playlist صحيحة.
- Made for Kids check.
- Rights check.
- Final QA PASS.

### Title Formula

**[المشكلة/المغامرة الجذابة] | لوما ودودو وبوبو**

العنوان طبيعي ومفهوم، لا Keyword stuffing ولا Clickbait مضلل.

## 8 — Playlist Architecture

- مغامرات لوما ودودو وبوبو.
- نتعلم ونلعب.
- عادات يومية جميلة.
- أغاني لوما ودودو وبوبو.
- اكتشف مصر.
- Shorts.

## 9 — Asset Rights Ledger

لكل Asset نسجل:

- Asset name/ID.
- النوع: Image / Model / Voice / Music / SFX / Font / Video.
- المصدر/الأداة.
- تاريخ الإنشاء/الترخيص.
- Commercial-use status.
- License/evidence location.
- Episode(s) used.

**Gate:** أي أصل وضعه القانوني غير واضح لا يدخل Final Master.

## 10 — Versioning & File Structure

**Episode ID:** EP01, EP02...

**Scenes:** SC01...

**Shots:** SH010...

**Version:** v001, v002...

مثال: EP01_SC02_SH030_ANIM_v004.

المجلدات القياسية:

01_BRIEF / 02_SCRIPT / 03_STORYBOARD / 04_AUDIO / 05_REFERENCES / 06_SHOTS / 07_EDIT / 08_MASTER / 09_THUMBNAIL / 10_RIGHTS.

## 11 — Notion Status Gates

Idea → Brief Approved → Script → Script Approved → Storyboard → Animatic Approved → Production → Edit → QA → Ready → Scheduled → Published → Review.

لا يتم تخطي Gate بسبب ضغط موعد النشر؛ الجودة أهم من كسر الـPipeline.

## 12 — KPI Review

**نراجع كل حلقة بعد:** 48 ساعة / 7 أيام / 28 يومًا.

نسجل، حسب ما يتيحه YouTube Analytics:

- Impressions.
- Thumbnail CTR.
- Views.
- Audience retention curve.
- Average view duration / percentage viewed.
- نقاط الهبوط الواضحة.
- أداء أول 30 ثانية.
- Traffic sources.
- Returning/New viewer signals عندما تكون متاحة.
- مقارنة الموضوع/الشخصيات/نوع الحلقة بالمحتوى السابق.

**قاعدة:** لا نغيّر الهوية بناءً على فيديو واحد؛ نبحث عن نمط عبر عدة حلقات.

## 13 — Monthly Review

كل 4 حلقات Long:

- أفضل Hook.
- أفضل موضوع.
- أفضل Thumbnail pattern.
- أكثر لحظة حصل عندها Drop.
- أفضل استخدام للشخصيات.
- ما الذي نكرر مبدؤه وليس نسخته.
- تحديث Backlog الحلقات القادمة.

## 14 — Production Stack Decision

- Planning/Script/QA: ChatGPT + Notion — معتمد.
- Character/Concept/Reference: ChatGPT Image Generation — معتمد للمرحلة الحالية.
- Video/Animation: Hybrid route؛ نختبر قبل القفل.
- 3D reusable assets: Blender عند الحاجة.
- Voice: Voice test أولًا؛ ثم تثبيت مزود/ممثل صوت.
- Music: Original/licensed only؛ تثبيت الأداة بعد اختبار الحقوق والجودة.
- Edit: Premiere Pro baseline أو بديل يحقق نفس الـMaster requirements.

**لا نقفل Video/Voice/Music provider قبل Pilot benchmark.**

## 15 — Pilot Benchmark

نختبر 3–5 Shots من EP01 تشمل:

- Close-up dialogue.
- Two-character interaction.
- Bobo action/comedy.
- Wide Egyptian environment.
- Shot بحركة كاميرا/شخصية أصعب.

نقيس: Character consistency، lip/performance، motion، environment consistency، render quality، controllability، الوقت والتكلفة.

الفائز يصبح Production Route v1.
